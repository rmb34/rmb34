## Engineering Focus

- Designing backend contracts, data models, authentication, authorization, and external integrations.
- Building production web applications with Next.js, React, TypeScript, and PostgreSQL.
- Evolving legacy Java systems without forcing modern patterns onto incompatible architecture.
- Protecting server-side invariants such as pricing, identity, tenant ownership, and state transitions.
- Testing behavior at the appropriate level: unit, real-database integration, HTTP, and browser workflows.
- Treating documentation, migrations, deployment boundaries, and operational verification as part of the implementation.
